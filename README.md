# Consent in Forensic Medicine · India

A self-contained educational webpage prepared for GitHub Pages. The quiz runs in the visitor's browser; answers are not submitted to a server.

## Publish with GitHub Pages

1. Create a new GitHub repository. Choose **Public** if you want anyone with the link to access the page.
2. Upload `index.html` and this `README.md` to the repository root, or push this folder as the repository contents.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for the Pages deployment to finish. GitHub will show the public site URL on the Pages settings screen.

If the repository is named `your-repo`, the URL usually looks like `https://your-username.github.io/your-repo/`. A user or organization repository named `your-username.github.io` uses `https://your-username.github.io/`.
